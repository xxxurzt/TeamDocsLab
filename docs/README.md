Описание проекта
TeamDocsLab — учебный проект, предназначенный для демонстрации настройки единого оформления программного кода и документации в команде разработчиков.

 Проект использует файлы .editorconfig и settings.json, которые помогают поддерживать одинаковые правила форматирования в Visual Studio Code.

Список функций:
- Настройка отступов с использованием четырёх пробелов.
- Использование кодировки UTF-8.
- Настройка переносов строк LF.
- Автоматическое удаление лишних пробелов в конце строк.
- Форматирование кода при сохранении файла.
- Хранение настроек редактора в проекте.
- Отслеживание изменений файлов с помощью Git.
